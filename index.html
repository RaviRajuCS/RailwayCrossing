Railway Crossing Warning Lights

Build a two-LED warning signal, understand the program, and use timing to create an alternating flash pattern.

Today's engineering mission

Create a model railway-crossing warning signal. LED A and LED B alternate: while one is ON, the other is OFF. The sequence repeats until the Arduino is stopped.

Identify LED anode and cathode.
Build two safe LED output circuits.
Use repetition and delay to control a pattern.

Learning model only: this is a classroom electronics exercise, not a safety-certified railway controller.

Current path for each LED: Arduino output → resistor → LED anode → LED cathode → GND. A resistor can be on either side of the LED electrically, provided it is in series. In this build it is on the anode side.

Identify D8, D9 and GND. Locate the terminal groups and centre gap.

Accuracy check: place each LED so its legs are in separate terminal groups on opposite sides of the centre gap. Connect each anode through its own resistor to its assigned pin. Connect both cathodes to GND. Wire colours are visual aids only; endpoints determine whether the circuit works.

3 · Arduino program explained

const int LED_A = 8;const int LED_B = 9;void setup() {  pinMode(LED_A, OUTPUT);  pinMode(LED_B, OUTPUT);}void loop() {  digitalWrite(LED_A, HIGH);  digitalWrite(LED_B, LOW);  delay(500);  digitalWrite(LED_A, LOW);  digitalWrite(LED_B, HIGH);  delay(500);}

Understand the instructions

const int gives each pin a meaningful name.

pinMode(pin, OUTPUT) configures a pin to send a digital signal.

digitalWrite(pin, HIGH) turns that output on; LOW turns it off for this LED circuit.

delay(500) pauses for 500 milliseconds, or half a second.

setup() runs once; loop() repeats the phases continuously.

Key idea: both LEDs are assigned opposite states in each phase. This is alternating output.

5 · Independent challenge: Make the warning faster

Make both LEDs alternate twice as fast.

  1. Find both delay(500) instructions.
  2. Predict what happens if both values become 250.
  3. Change the program in Tinkercad and run it.
  4. Explain why the wiring does not need to change.
Hint: 1 second = 1000 milliseconds.

Answer: 250. Change both delays to 250 milliseconds. The pins and wiring remain unchanged because only timing instructions change.

Extension

Add a pause in which both LEDs are OFF for 200 milliseconds between flashes. Write the extra instructions and test your result.
